# 实验一需求规格

## 项目背景与范围

本项目面向需要整理动漫插画、图形素材和静态照片的学生用户，建立可复现的图像处理入口。用户自行提供彩色、灰度及不同尺寸图片，通过命令行指定输入与输出路径。系统读取图像，检查尺寸、通道和数据类型，将彩色图转换为灰度图并无损保存，同时记录状态、耗时和版本。原始素材保持不变，路径错误、损坏文件及保存失败应明确反馈。此次只交付需求、环境、基线程序和测试证据，不实现增强、边缘、分割、角点、尺度空间、复杂识别或图形界面；替换素材后沿用同一接口重新执行。

## 功能需求

| 编号 | 给定输入与执行行为 | 可验证结果 | 验证方法 |
| --- | --- | --- | --- |
| FR-01 | 给定存在且可解码的静态图片路径，执行 `--input` 读取 | 得到非空 NumPy 图像数组 | T01、T02、T04、T05 |
| FR-02 | 读取成功后检查数据属性 | 输出 shape、dtype、ndim、channels、通道顺序及像素范围 | T01/T04 的 JSON 日志 |
| FR-03 | 给定 3 通道 BGR 图或单通道灰度图，执行灰度转换 | 彩色变单通道，灰度像素保持，尺寸和位深保持 | T01、T04；逐像素回读比较 |
| FR-04 | 给定 4 通道 BGRA 图，按指导书处理 Alpha | 丢弃 Alpha、不合成背景，日志标记 Alpha 策略 | T05；输出与独立 BGRA2GRAY 结果比较 |
| FR-05 | 给定 `.png` 输出路径且父目录不存在，执行保存 | 自动建目录，生成非空且可回读的无损 PNG | T08；文件大小、属性和像素检查 |
| FR-06 | 给定中文输入和输出路径，执行处理 | 成功读取和保存，不依赖 ASCII 文件名 | T06 |
| FR-07 | 给定新图片和新路径配置，不修改源代码再次运行 | 按实际尺寸处理，生成新批次与输入哈希 | T11、按 reproduction.md 换图复现 |
| FR-08 | 给定 `--record`，或执行批量测试 | 保存成功/失败、输入输出属性、版本及处理耗时证据 | T01、各用例日志及 results.json |

## 非功能需求

| 编号 | 条件与要求 | 验证方法 |
| --- | --- | --- |
| NFR-01 | 在 environment.md 记录的平台，对 1920×1080 三通道 uint8 图像，基线读取到保存耗时参考目标 ≤2000 ms；更大图另报尺寸与耗时 | T10 的 elapsed_ms 与平台记录；性能单独评价 |
| NFR-02 | 安装与运行采用独立虚拟环境，所有安装依赖记录确切版本，导入 OpenCV/NumPy/Matplotlib 成功 | version_check.py、requirements.txt、pip check |
| NFR-03 | 路径从命令行/配置传入，主流程有 main；另一同学可仅按 README 复现 | 源码检查及 README/reproduction.md 步骤 |
| NFR-04 | 原始数据不得被程序修改，输出与输入分离 | 所有原图执行前后 SHA-256 相同；T13、T15、T17 |
| NFR-05 | 状态机器可解析，失败返回非零；每个实验只保留最新一次完整个人结果与证据，新结果通过校验后替换旧结果 | JSON 状态、退出码、lab1_latest/lab2_latest 目录与结果替换测试 |

NFR-01 是平台相关性能参考，不以任意更大图的耗时判定转换功能失效，也不以一次测量宣称所有平台均满足性能目标。

## 异常处理需求

| 编号 | 异常输入或条件 | 预期行为 | 验证方法 |
| --- | --- | --- | --- |
| EX-01 | 输入不存在或不是文件 | ERROR，明确指出路径，退出码 1，不访问空对象属性 | T03 |
| EX-02 | 文件损坏、为空或不能解码 | ERROR，说明读取失败，退出码 1 | T07 |
| EX-03 | 输出为目录、无权写入或 PNG 编码/保存失败 | ERROR，说明目标或原因，退出码 1 | T12；异常捕获检查；无权写入需在对应平台另测 |
| EX-04 | 不支持的 shape 或 dtype | ERROR，不做隐式类型缩放 | 自检 T18/T19；validate_image 检查 |
| EX-05 | 输出覆盖输入、写入 data/input、日志与输出相同 | 写入前拒绝，原图不变 | T13、T15、T17 |
| EX-06 | 输出不是 `.png`，或缺少必要命令行参数 | 前者 ERROR/退出 1；后者参数帮助/退出 2 | T14；手动省略参数验证 |

## 用户用例

| 编号 | 前置条件与操作 | 正常结果或异常分支 |
| --- | --- | --- |
| UC-01 正常处理 | 用户已提供合法彩色 PNG，以 --input/--output 执行 | 打印属性和 SUCCESS，得到同尺寸单通道 PNG |
| UC-02 文件不存在 | 用户输入不存在的文件路径 | 明确提示文件不存在，退出非零，不生成输出 |
| UC-03 灰度输入 | 用户提供真正单通道 PNG | 保持像素及位深，保存成功，不访问不存在的第三通道 |
| UC-04 输出目录不存在 | 输入有效，输出父目录尚未建立 | 自动创建父目录并成功保存；若父目录不可写则明确报错 |

## 验收标准

| 编号 | 可判定条件 | 证据 |
| --- | --- | --- |
| AC-01 | 环境为独立虚拟环境；三项核心库导入成功，依赖检查通过 | environment.md、requirements.txt、依赖检查日志 |
| AC-02 | 彩色 PNG/JPEG 输入返回 SUCCESS/0，结果为单通道、同尺寸且同 dtype | T01/T02 实际日志及灰度结果 |
| AC-03 | 灰度输入不改变像素，透明输入按明确的 Alpha 策略处理 | T04/T05 逐像素校验及 alpha_policy |
| AC-04 | 不存在路径和损坏文件返回 ERROR/非零，程序给出原因 | T03/T07 日志 |
| AC-05 | 新输出目录自动建立，中文路径可读写 | T06/T08 日志和文件 |
| AC-06 | 黑白及不同尺寸图可处理，大图有尺寸、耗时及版本记录 | T09a/T09b/T10/T11 |
| AC-07 | 至少八个实际测试有命令、退出码、预期/实际状态和输出属性证据 | test_report.md 与对应 evidence 批次 |
| AC-08 | 输入没有被程序修改，更换素材无需改源码即可再次运行 | 前后哈希、T13/T15 及配置重跑 |
| AC-09 | 需求、环境、源码、README、测试报告及两个用户指南齐全 | 项目文件检查 |

AC-07 分开评价“代码已实测”和“用户个人素材已实测”：自检报告只证实前者；正式图片验收必须在你提供素材后重新执行，不能将待执行用例填写为通过。
