# 预处理模块编码规范

适用实验一至四的Python模块。以下是已可用于本项目的技术规范，小组需在真实讨论后确认或修改，不预填批准记录。

## 命名与职责

文件、函数、局部变量采用snake_case；常量大写；类使用PascalCase。图像变量明确gray/bgr/magnitude等语义，区分显示图与原始数值，不用归一化幅值替代真实导数。

数值模块只处理数组和参数，不访问文件。run_labN.py负责路径、参数、证据和报告；test_labN.py负责边界/数值自检；package_labN.py负责源码包。共享IO与latest逻辑复用已有模块，不复制不受保护的清理代码。

## 注释与数据约定

用户文档和异常提示使用中文，关键技术标识保留标准英文；注释说明坐标、位深、边界、取整和例外的原因。函数使用类型标注及必要docstring；四空格缩进，无全局随机种子副作用。复杂表达式应优先拆开便于检查，后续整理格式不改变数学行为。

NumPy使用img[y,x]，特征坐标xy，BGR显示需转RGB。实验三/四uint8，梯度/评分先用有符号或浮点，显示时再转换。随机过程使用default_rng并记录种子。所有输入只读，返回新数组；不偷偷resize、不静默转换位深、不自动改变分割语义。

## 参数、错误与证据

所有路径通过配置或命令行，默认值进入报告；拒绝不合法核、NaN阈值、错误通道等。接口抛出清晰异常，一键入口输出ERROR并退出非零，不把失败写成SUCCESS。图片编码/回读失败必须报告。PSNR∞在JSON使用null+标志，JSON禁用NaN。

个人输出固定实验latest目录，新结果校验后替换。清理目标检查绝对路径在项目指定结果根内，拒绝越界与链接；原始输入和其他实验结果不删。源码ZIP不含虚拟环境、缓存、个人原图或历史输出。

## 验证与走查

测试覆盖独立已知值、边界、异常、数组不变和结果保留；避免只将同一函数输出当期望。数学定义、原始与显示尺度、参数来源、无标签时的结论范围需要走查。修改数值/边界逻辑后执行对应自检及必要个人案例；文档修改检查命令、路径与图像链接。

每个实验结束同步更新统一reproduction.md、image_requirements.md，并更新user_tasks.md的真实待办状态；不将学生未完成的活动自动勾选。
