# 各实验个人图片要求

统一记录实验一至六的图片条件。后续每完成一个实验，都增加素材条件、输入来源与派生方法，并同步更新reproduction.md。规则已写入AGENTS.md；需要你实际补充的事项另见user_tasks.md。

正式素材由你提供。实验五是已明确授权的例外：程序绘制标准棋盘作为本次正式素材，注明来源，不冒充实拍。程序按指导书从你的图导出格式、尺寸、亮度、Alpha 或噪声版本，明确记录方法，不下载其他图片，也不把自检随机数组当作个人素材。原图保持不变。

## 共用条件与当前来源

图片放在 data/input，推荐单张静态 PNG/JPEG，实际导出指定格式，不只改扩展名。中文/空格路径支持，命令中加引号。JSON相对路径按project_i根目录解释，绝对路径建议正斜杠。原图不能放到 data/output、docs 或 evidence。

当前来源为你提供的DreamEnding_swing_dusk.jpg（1192×671、三通道uint8）、black.png、white.png；photo.jpg为源JPEG副本。二至四的常规纹理主图是data/input/photo.jpg。2026年10月20日你明确提供uneven_real.jpg建筑夜景实拍图（4096×3072、BGR uint8），用于四的光照不均和六的SIFT主图。同图派生版本不会被描述为独立拍摄照片。

## 实验一素材

| 配置项 | 默认文件 | 必须满足的属性 |
| --- | --- | --- |
| color | color.png | 真实PNG，三通道彩色，有颜色变化 |
| jpeg | photo.jpg | 真实JPEG，三通道，可复制源JPEG字节 |
| gray | gray.png | 真实PNG，真正单通道；黑白外观的RGB不符合该项 |
| rgba | rgba.png | 真实PNG，四通道，建议透明/半透明/不透明区域 |
| different_size | different_size.png | 高或宽至少一项与color不同 |
| large | large.png | 至少2073600像素，性能比较优先1920×1080 |
| black | black.png | 全部分量均为0 |
| white | white.png | 所有分量为位深最大值，uint8为255 |

完整正式测试需要角色齐备；单张基线只需一张合法图片。同一作品可以导出多种版本，不需八幅作品。推荐uint8，实验一也支持uint16保持位深。

prepare_inputs.py --source 创建新的 data/input/prepared_ 目录，导出彩色PNG、真正灰度、Alpha分区、缩小图、1920×1080等比例调整/补边大图及JPEG，沿用你的黑白图并更新 images.json。原RGB保持，Alpha分区仅用于通道测试；舍弃Alpha后隐藏颜色仍参与灰度。放大只作尺寸/性能测试，不增加原图细节。

准备阶段创建派生输入，实验处理仍禁止写入原图目录。不用提供损坏个人图片，文件不存在/损坏测试在证据目录制造异常条件。

## 实验二素材

config/lab2_images.json 中 normal 为正常亮度，dark 为偏暗，low_contrast 为低对比度；均为uint8，PNG/JPEG或单通道灰度均可。暗图应有可辨识暗部，正常图避免大片全黑/过曝，低对比度图灰度范围较窄。

normal与dark的高宽必须相同，运算程序不自动拉伸。不同内容可以混合，但不把未对齐像素差解释为真实运动。手写/API均衡化限定灰度uint8，uint16/float32明确拒绝。

已获你确认：dark/low_contrast=null时从同一源图按0.45*gray、0.3*gray+80生成，保存在本次输出inputs，来源和参数写入报告；填写路径则使用你另提供的图片。它们不是两次独立拍摄的照片。

## 实验三素材

config/lab3_images.json 的input为清晰参考图，也可由 run_lab3.py --input 覆盖。必须uint8，宽高至少7；推荐640×480至1920×1080，具有清楚轮廓和细纹理，街道、建筑、发丝/织物细节插画均可。避免严重模糊、大面积过曝及强烈既有噪声。

本次沿用你的插画，不需另提供含噪图。按指导书生成高斯噪声（sigma=25、seed=0）与椒盐噪声（黑白各0.05、seed=1），保存至lab3_latest，记录种子和选中比例。这两类噪声图属于实验输出，重跑后只留最新完整结果。

评分以同一参考和同尺寸结果进行，不能用真实未知噪声图同时冒充无噪声真值。JPEG可作固定参考，其既有压缩痕迹属于参考信号；PNG可避免额外压缩。不要为了SSIM的7×7条件把极小图临时放大再宣称有效保真。

彩色转灰度用于滤波评分，BGR接口另用三通道调用。灰度输入在加载边界转BGR，RGBA舍弃Alpha；preprocess自身严格接收H×W×3的BGR。

## 实验四素材

config/lab4_images.json的texture为清晰纹理图，uneven为光照不均图。两图分别运行边缘/阈值分析，无像素相加，不需同尺寸。推荐uint8静态PNG/JPEG，640×480至1920×1080，主入口最短边至少5，观察自适应窗口建议宽高均≥31。

清晰纹理图宜有方向不同的轮廓、线条和细纹理；现有插画中的绳索、发丝、衣物和背景轮廓适合观察。光照不均图宜有真实明暗区域和局部细节，例如窗边、室内阴影；避免仅全黑/全白或大面积过曝无细节。

当前uneven已由你替换为data/input/uneven_real.jpg实拍图并写入配置。2026年10月20日简单验证：4096×3072、BGR uint8，内容为建筑夜景，有局部照明、暗部和轮廓；文件/内容适用，12项正式检查、26张结果通过，实拍图Otsu=66。原图保持，用户任务仅该素材替换一项据明确说明标记完成。此前uneven=null的0.35→1.0同图增益模拟已不是当前正式输入；未来设回null时仍可复现，来源标为模拟。

阈值分割只表示灰度区域。若希望评估“人物分割正确率”或真实边缘准确率，还需要明确的人工目标标签；当前实验没有这些标签，因此不编造准确率。手写与OpenCV的边缘IoU仅是一致性。

## 实验五素材

必需棋盘路径为config/lab5_images.json的chess，默认data/input/chess.png；通过run_lab5.py --chess覆盖。用户已明确授权程序绘制作为正式素材：8×8格、每格40像素、320×320、全黑/全白交替，内部7×7=49个几何交点。prepare_chess.py生成灰度PNG并记录授权/尺寸/哈希；不使用网络素材，不称实拍。已有不同内容的同名文件拒绝覆盖。

若提供自己的棋盘，建议棋盘边缘清晰、黑白反差明显、格子完整，每格至少20像素，至少5×5格便于形成足够内部交点。正视图适合参数对比；斜视、旋转、模糊或曝光变化可另做拓展，记清来源。避免格子过小、裁切过多、低分辨率严重压缩及反光遮挡。正式入口最短边16只是程序下限，满足下限不代表足够的实验质量。

单张静态PNG/JPEG、uint8；灰度/BGR/BGRA在读取边界明确转灰度，16位/float输入拒绝。角点核心接口仅接收二维uint8。换图后按实际尺寸计算金字塔，奇数尺寸取ceil(n/2)，不把你的图强制拉成320×320；来源记录仅在输入哈希匹配时沿用生成棋盘说明。

补充纹理图由texture字段指定，当前为你提供的photo.jpg。它用于说明FAST/角点在个人插画中的表现，不代替棋盘必做项；与棋盘无需同尺寸，texture=null可以省略。建议有多个方向的交界、清楚纹理，沿用现有插画即可。

无需自己准备金字塔或DoG图，程序从所选棋盘生成，这些属于最新实验输出。自检用的人工交点/随机数组与正式素材分开记录。如果教师要求真实拍摄棋盘，按user_tasks.md补实拍；当前授权生成素材本身已齐备，不自动推断你完成了个人复现或截图。

## 实验六素材

需要一张具有多个方向轮廓、角部、纹理的个人照片，建议建筑、街景、书籍/物体细节，避免严重虚焦、过曝、纯色或只有重复图案。当前直接使用你提供的建筑夜景uneven_real.jpg，不需重新供图；虽偏暗但可检测2455个SIFT实例，参数和变换对比均已完成。重复窗格会造成误匹配，已用生成矩阵核验，而不要求你为提高数值另拍图。

config/lab6_images.json的input指定主图，可用run_lab6.py --input覆盖。支持uint8静态PNG/JPEG、灰度/BGR/BGRA，BGRA舍弃Alpha；不自动缩放16位/浮点到uint8。正式入口最短边≥16，但极小/纯色图没有足够特征，不能据成功退出码当作完成有效实验。

建议分析图640×480至1920×1080；原始大图可直接提供。max_input_side=1600只对超出上限的原图做INTER_AREA等比缩小，当前4096×3072→1600×1200；设0保持原尺寸。原始文件不修改，工作图另存working_input.png，记录像素中心映射；若缩小后最短边不足16则报错，不拉伸补足。

你无需预先制作旋转/缩放图。按指导书从工作图生成30°、0.6倍和组合版本，扩展画布防止裁切，保留矩阵，用于受控验证；这些不是三次独立拍摄的照片。缩放/插值和黑色补边会改变部分特征，匹配比例如实报告。不要为了超过经验比例阈值替换或删改不利匹配。

更换成其他个人照片或已有插画时无需改源码，路径/尺寸/描述子/统计会重新计算；如课程限定照片，正式提交沿用已提供实拍即可。完整真实多视角或物体转动素材是后续实验范围，本次不要求。

## 更换与原图保护

六个实验使用独立配置：images.json、lab2_images.json、lab3_images.json、lab4_images.json、lab5_images.json、lab6_images.json。换成统一新源图时，先准备一的角色，再同步改二至六的常规/纹理配置或用各自图片覆盖参数；五的棋盘单独准备。只改images.json不会更换其他实验。

每次记录原文件前后SHA-256。新个人结果校验后替换旧结果，失败保留此前完整结果；原图和派生输入不随结果清理。亮度/噪声输出与事先准备的输入素材分开。保护由程序实施，没有代改Windows ACL，可自行备份原图。

未来实验需要成组视角或特殊素材时，在新章节明确新增条件，不猜测未开始实验的要求。
